# Visual direction
The detailed brief delegates routine choices; this implementation proceeds directly without an additional design approval flow.
Grounded directions considered: architectural publishing; material sample library; construction schedules; modern Philippine civic wayfinding; topographic atlases; university engineering publications; cooperative workshop signage.
Direction 4: civic wayfinding. Deep forest navigation, warm drawing surface, orange selection, teal water and violet electrical layers. Familiar desktop navigation and inspector. Signature: a compact dependency trail showing the path from edit through checks to quantities.
Operate mode: fixed navigation rail, project/layer sidebar, central scaled drawing, and a right properties inspector or collapsible Cursor-style agent dock. New-project composition uses a persistent conversation beside the live plan and a traceable brief/edit history. Spacious canvas, compact tabular evidence. Geist sans and mono for measurements only. Keyboard focus, clear disabled/loading/error states, responsive panel collapse.

Staged planning extends the composer using the same forest conversation panel, light drawing canvas and adjacent inspector. The primary launch action is **Start planning**. A persistent ordered stage bar exposes programme, site/access, spatial layout, detailed layout, design acceptance, engineering inputs, screens and review package. Later steps unlock after confirmation; revisiting earlier stages creates candidates and invalidates downstream acceptance and results when applied. Earlier concept drafts and the coordinated template remain separate, clearly labelled paths.

The architectural agent leads the design conversation; the coordinator applies typed candidates and owns stage gates. In screens, a compact specialist roster separates architecture, structure, fire/accessibility, electrical, plumbing, site/traffic and quantities. Each role shows deterministic status independently from whether a live AI review exists. Advice links to finding evidence or input references; it never appears as calculation or certification.

Plans use real polygon geometry, numbered spaces and individually selectable objects with accessible schedules. Site/building extents, zoom and room/object/route layers remain explicit controls. Native drawing/site readings are reviewed before use. Forms expose values and provenance rather than raw JSON. Draft import revalidates each stage; prior approval is not restored. Recoverable local form edits remain distinct from server-saved immutable candidates. The design-acceptance screen lists unresolved items and requires acknowledgement. Screens and exports identify current coverage and incomplete pricing. On narrow screens conversation, drawing and inspector stack without removing controls; stage navigation stays scrollable and keyboard accessible.
