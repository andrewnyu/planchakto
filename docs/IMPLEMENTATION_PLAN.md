# Implementation plan
1. Typed SI model, synthetic fixture, immutable branchable revisions, idempotent commands, SQLite persistence.
2. SVG plan editor, synchronized physical 3D, geometry-derived takeoff, editable selected objects.
3. Linear Euler–Bernoulli beam finite elements; independent simply supported roof beams, service and user-defined factored loads; verify against closed form. Restricted centered bearing screen.
4. Geometry-verified orthogonal routing, circuit totals, cold water and gravity drain slopes, explicit obstacles and fittings.
5. Server-only Gemini structured commands, validated through the same domain pipeline. Unconfigured state remains explicit.
6. CP-SAT room ordering and allocation within two strips and a fixed corridor, locks, adjacency and door access, transparent scores.
7. Terrain imports/triangulation, exports/report, numerical and browser acceptance, deployment packaging.

Scope exclusions: whole-building frame stability, connections, column buckling, lateral/seismic/wind design, hydraulic/vent design, electrical protection/sizing and PH code certification. Unsupported inputs/results remain visible.
